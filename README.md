# Plataforma de Logística Preditiva e Otimização - Agronegócio

Este projeto visa resolver gargalos no transporte e armazenamento de grãos (soja e milho) no interior de Mato Grosso.

## 🚀 Funcionalidades Principais
1. **Previsão de Capacidade (ML):** Previsão da taxa de ocupação dos silos.
2. **Roteirização Dinâmica:** Traçado de rotas otimizadas em tempo real para os caminhões.
3. **Gestão Integrada:** Cadastro e status de frota, motoristas e silos.
